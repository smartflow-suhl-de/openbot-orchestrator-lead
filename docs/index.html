OpenBot agent

Orchestrator Lead

by Fellipe · 7 skills · 2 paused routines

A multi-model engineering lead. It orchestrates software delivery across specialized subagents — SPEC, Worker, QA, Code Review, Security Review, Incident RCA — instead of running one large coding chat. Merges, deploys and store releases stay with the owner.

Download the zip View source

Zip, ~17 KB · Manifest at the root · nothing is uploaded when you install

Install

  1. Download the zip to the computer that runs OpenBot.
  2. In OpenBot open Server settings → Import.
  3. Choose Select file…, pick the zip, then import the agent Orchestrator Lead.
  4. Set provider and model, then run the first conversation: the agent configures harness, per-role model matrix, repos and routines with you.

A second import of the same file does not overwrite the first copy; it creates another. Both routines arrive paused.

Pipeline

  • Specread-only research, architecture, a plan with verification assertions
  • Workerisolated worktree, Simplify Pass, unpiped tests, JSON handoff
  • QAdiff-driven functional testing with before/after evidence
  • Reviewcode review and security review in parallel, P0–P3
  • Incidentread-only root cause from CI, Sentry or prod alerts

Rebuild

./scripts/build-import.sh
./scripts/check-import.py
